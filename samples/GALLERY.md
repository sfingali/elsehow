# Gallery

Each film renders in **2D** and **2.5D**. The default image is the **atlas**
(the chart). The **record index** — every retained value, evidence, assumption,
profile parameter and unresolved reference — is a separate image. The **SVG** is
the full-resolution vector master (crisp at any zoom).

*(Sensitive/unpublished screenplays are deliberately excluded.)*
